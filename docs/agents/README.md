# ScoutLGS agent operations

These documents make agent-assisted work reviewable and repeatable. They do
not grant authority beyond a user request, repository permissions, or
`AGENTS.md`.

| Document | Use it when |
| --- | --- |
| [Operating model](OPERATING_MODEL.md) | choosing the task's autonomy level, checkpoints, or delivery path |
| [Runbooks](RUNBOOKS.md) | investigating CI, storefront, or release-readiness work |
| [Evaluation](EVALUATION.md) | defining acceptance evidence or reviewing an agent result |
| [Handoff template](HANDOFF_TEMPLATE.md) | preparing an issue, PR, or final task report |
| [Decisions](DECISIONS.md) | a durable product or architecture choice affects later work |
| [Repository guardrails](REPOSITORY_GUARDRAILS.md) | enabling the GitHub controls that enforce the written policy |

`AGENTS.md` is the concise entry point. Keep durable policy in one canonical
location and link to it instead of maintaining competing summaries.

The repository skills in [`../../skills`](../../skills/README.md) contain
procedural guidance for recurring workflows. They do not replace the safety or
approval boundaries in `AGENTS.md`.
